# KVoice

KVoice is a native macOS command-line application for speech recognition, text-to-speech, text optimization, timestamped transcripts, and semantic text location. It is written in Swift and uses Apple's Speech, Foundation Models, and AVFoundation frameworks. Processing is performed locally.

[View the KVoice repository on GitHub](https://github.com/KuekHaoYang/KVoice).

## Requirements

- macOS 26 or later.
- Swift 6.4 or an Xcode toolchain that includes Swift 6.4 or later.
- Apple silicon and Apple Intelligence for features that use Foundation Models.
- Speech recognition assets and text-to-speech voices may need to be downloaded or enabled in macOS.

KVoice has no third-party package dependencies and does not use a server or external HTTP service.

## Build and run

Build and run the package with Swift Package Manager:

```sh
swift build
swift test
swift run KVoice help --output ./KVoice-help.txt
```

After building, the executable is available at `.build/debug/KVoice` when using the default SwiftPM configuration. Command invocations require an output path, including `help`, `version`, and resource-list commands. Paths may be absolute or relative to the current working directory.

Command examples use `KVoice` to refer to the executable. Run them as `swift run KVoice <command> ...` from the package root, or use the built executable's path.

The complete command reference is generated by `KVoice help --output <path.txt>`. The source of truth for command flags, formats, defaults, and examples is [`HelpText.swift`](Sources/KVoiceCore/HelpText.swift).

## Speech-to-text

Transcribe an audio file. Foundation Models transcript correction is enabled by default:

```sh
KVoice transcribe \
  --input ./interview.m4a \
  --output ./interview.txt
```

Select a language and skip transcript correction:

```sh
KVoice transcribe \
  --input ./meeting.wav \
  --output ./meeting.txt \
  --language ms-MY \
  --no-optimize
```

Write a timestamped JSON transcript:

```sh
KVoice transcribe \
  --input ./lecture.m4a \
  --output ./lecture.json \
  --timestamps
```

The JSON document contains `language`, the raw `transcript`, `optimizedTranscript`, and `segments`. Each segment has `text`, `startSeconds`, and `endSeconds`. A segment can cover one word or a longer text run, according to the time ranges supplied by Apple's Speech framework. KVoice does not infer word-level boundaries.

### Automatic audio-language selection

Apple's `SpeechTranscriber` requires a locale before recognizing audio. Foundation Models accepts text prompts, not raw audio. In automatic mode, KVoice starts with the system-preferred installed Speech locale, uses Foundation Models to classify the first transcript against locally installed Speech locales, then transcribes again if the predicted language differs. This is a heuristic rather than acoustic language detection before transcription. Short, noisy, or mistranscribed audio can lead to an incorrect selection. Specify `--language <BCP-47>` when the spoken language is known; an explicit supported locale may require a model asset download.

## Text-to-speech

Read UTF-8 text from a file, optimize it, detect its language with Foundation Models, then synthesize a WAV file:

```sh
KVoice speak --input ./note.txt --output ./note.wav
```

Paths may be relative to the current working directory. To sanitize Markdown before optimization and synthesis, use `--sanitize-markdown`. Headings, emphasis, list markers, links, and code delimiters are removed; link and image labels and fenced code contents are retained as text. `--strip-markdown` is an alias.

```sh
KVoice speak --input ./note.md --output ./note.wav \
  --sanitize-markdown --no-optimize --language en-US
```

Text can also be passed as one shell argument:

```sh
KVoice speak \
  --text "Good morning. This is a KVoice speech test." \
  --output ./test.wav \
  --language en-GB
```

Use `--no-optimize` to synthesize source text without text correction. Automatic voice selection uses voices installed on the Mac. Explicit language tags use BCP-47, such as `en-US`, `zh-CN`, or `ms-MY`.

Select an installed voice by its displayed name and set Apple's utterance rate:

```sh
KVoice speak --input ./note.txt --output ./note.wav \
  --voice Samantha --rate 0.57 --language en-US
```

`--rate` accepts values from `0.0` (minimum) to `1.0` (maximum). Apple defines `0.5` as the default. KVoice validates values against Apple's `AVSpeechUtteranceMinimumSpeechRate` and `AVSpeechUtteranceMaximumSpeechRate` constants; when omitted, the system default is used. See Apple's documentation for the [voice catalog](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoice/speechvoices()), [voice properties](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoice/identifier), and [utterance-rate constants](https://developer.apple.com/documentation/avfaudio/avspeechutterancemaximumspeechrate).

Use `KVoice list voices --output ./voices.txt` to list installed voice names, identifiers, locales, and quality. Use `KVoice list languages --output ./languages.txt` to list installed and supported Speech recognition locales and languages available through installed synthesis voices.

Text can be read from standard input by passing `-` to `--input`:

```sh
cat ./note.md | KVoice speak --input - --output ./note.wav \
  --sanitize-markdown --language en-US
```

To convert every regular file recursively in a directory, pass a directory to `--input` and an output directory to `--output`. Directory structure is preserved and output extensions become `.wav`:

```sh
KVoice speak --input ./notes --output ./audio \
  --language en-GB --no-optimize
```

## Locate source text in a reference

Provide a UTF-8 reference document and exactly one source. The source can be a text file:

```sh
KVoice locate \
  --reference ./lecture.txt \
  --source-text ./quote.txt \
  --output ./quote-location.json
```

Or provide audio. KVoice transcribes it first, optimizes the transcript by default, then uses Foundation Models to find a corresponding passage in the reference:

```sh
KVoice locate \
  --reference ./lecture.txt \
  --audio ./clip.m4a \
  --output ./clip-location.json \
  --language en-US
```

The JSON contains `originalSourceText`, `processedSourceText`, optional `language`, and `location`. A found location contains a verbatim `excerpt`, a zero-based `startUTF16`, and `lengthUTF16`, using `NSString` range coordinates. KVoice checks that the excerpt occurs in the reference before returning it. The on-device model may miss a semantic match or propose a weak one; inspect the excerpt and offset for important work.

## Output behaviour

- Absolute paths and paths relative to the current working directory are accepted.
- `transcribe` writes `.txt`, or `.json` with `--timestamps`; `speak` writes `.wav`; `locate` writes `.json`.
- Every invocation requires `--output`; use `help --output ./help.txt` to save the command reference.
- Existing output files are preserved by choosing `name copy.ext`, then `name copy copy.ext`, and so on. Use `--force` to replace the requested output.
- `--no-optimize` disables text correction only. Automatic language selection still uses Foundation Models.
- `locate --source-text` searches the supplied text as-is; `--no-optimize` affects only audio transcripts.
- Generated files are written to the selected output path and the resulting path is printed to standard output. Errors go to standard error and return a nonzero exit code.
- If Foundation Models is unavailable, default optimization and automatic language selection fail with an actionable error. Use `--no-optimize` with an explicit `--language` to avoid Foundation Models for transcription or speech synthesis.

## Architecture

The Swift package has three targets:

- `KVoiceCore`: argument parsing, domain models, file validation, orchestration, and framework adapters.
- `KVoiceCLI`: a minimal asynchronous process entry point and standard-error/exit-code handling.
- `KVoiceCoreTests`: deterministic tests using protocol fakes, plus opt-in Apple framework integration checks. Default tests do not call Foundation Models or download Speech assets. Set `KVOICE_RUN_SYSTEM_TESTS=1` when running `swift test` to opt in to tests that exercise Foundation Models, installed voices, and Speech model assets.

Framework boundaries use `LanguageModeling`, `SpeechRecognizing`, and `SpeechSynthesizing` protocols. The command runner controls operation order and output serialization; native adapters contain Apple API interactions. `TextChunker` bounds ordinary prompts and preserves whitespace-bearing words where possible. Text matching uses model-proposed excerpts and deterministic UTF-16 range verification.
